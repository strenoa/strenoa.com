# strenoa.com

## Cursor Cloud specific instructions

This repository is a GitHub Pages placeholder for the domain `strenoa.com`. It currently contains only `README.md` and a `CNAME` file (the GitHub Pages custom-domain binding). There is no application code, no package manifests, no lockfiles, no build tooling, and no services.

- There are no dependencies to install and nothing to build. The update script is intentionally a no-op.
- "Running the app" means serving the repo as a static site the same way GitHub Pages does. From the repo root: `python3 -m http.server 8000` (Python 3 and Node 22 are preinstalled). Then open `http://localhost:8000/`.
- There are no lint or automated test suites configured.
- If real static content is added later (e.g. an `index.html`, assets, or a static-site generator), update this section and the update script accordingly.
